** FIXED #9 Copy and paste public keys with NIP-19 npub

Resolution: pure Til NIP-19 codec accepts npub and nprofile, including NIP-21
nostr: wrappers, alongside case-normalized hex. It validates Bech32 (not m),
uniform case, checksum, conversion padding, exact 32-byte identity and bounded
TLV framing. Unknown nprofile TLVs are ignored; relay hints do not change routing.
The shared account owner normalizes both GUI and CLI follow/unfollow input to
hex before storage, preserving one identity/petname across presentation forms.

GUI Key/Copy key/author-line controls now copy canonical lowercase npub. Added
a header Copy npub button for the active account, and enlarged public-identity
input for profile/URI forms. An empty/unavailable text clipboard now reports a
message rather than dereferencing the null GLFW result, discovered during the
real copy/paste check. The codec's owned-string APIs and presentation-only
boundary are documented in [[file:../../doc/accounts.org][accounts]]. No DNS/NIP-05 resolver, private-key
import or event/address-entity decoder was introduced.
