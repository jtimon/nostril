** FIXED #11 Adopt installed Til UTF-8 and grapheme APIs

Resolution: core Str.from_codepoint/read_utf8/is_valid_utf8 now own Unicode
encoding, strict JSON decoding and validation. Removed Nostril's duplicate
UTF-8 encoder/decoder implementations. The existing public validation wrapper
delegates to core, including account-name checks. No text normalization occurs;
malformed reads are rejected rather than repaired with U+FFFD.

GUI Backspace and width/status clipping now use std/unicode's extended grapheme
boundaries, following Tiled. The composer retains its 280-scalar budget and
recounts after deleting a multi-scalar cluster. Protocol subscription IDs retain
64-scalar limits; account names retain byte limits. ASCII petname/Bech32 contracts
remain unchanged. [[file:../../doc/unicode.org][Unicode documentation]] covers boundaries, exact-byte signing,
font/IME limitations and SDK ownership of Unicode data/notices.

The new compiler's ownership checker also rejected direct WsOwner construction
followed by transfer into its registry: it traced the owned child allocation as
used after its constructor consumed it. Explicitly naming the child did not
resolve that diagnostic. A dedicated WsOwner.new constructor scopes the child
transfer and returns one complete owner, retaining heap-stable callback state
without cloning native handles. A reduced constructor/registry probe passed
under ASan; this is an explicit construction boundary, not a compiler fix.
