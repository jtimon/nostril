* Building and running Nostril

[[file:../README.org][Nostril]] | [[file:architecture.org][Initial architecture]]

** Requirements

The generated [[file:til-dependency.org][Til build dependency]] records the compiler used by the
last successful full build; =make.til= updates it automatically.

Nostril requires an installed Til whose support tree includes =std/crypto=,
=vendor/bindings/secp256k1.til=, and both =libsecp256k1.a= and its interpreter
shared-library twin (=.so=, or =.dll= on Windows; check the compiler with
=til -v=). The =til= executable, Git, CMake
3.24 or newer, and a C compiler must be on =PATH=, and the source must be built
from a Git checkout. Like Tiled, the build driver uses a compile-time macro to
derive the =0.0.1-<short-commit>= version; it generates the library's shared
version constant before building. The graphical client also requires the GUI
dependencies supplied by the Til installation.

The local client and relay use the project-owned NNG =v1.11= snapshot under
=vendor/nng/=, pinned to upstream commit
=84aa701f42968bf536141a24e826da66963b571a=. The driver configures a release,
position-independent static build with NNG's tests, tools, and TLS disabled.
It then creates =gen/nng/libnng.a= and force-loads that same archive into the
=libnng.so= twin required by Til's interpreter. No Til source checkout or
system NNG package is used. This native twin command currently targets the
Linux/GNU linker and links =pthread= and =atomic= explicitly.

The driver also compiles =lib/feed.c= into =gen/nng/feed.o= and adds it to both
NNG artifacts. Its targeted-message helpers share NNG's socket registry in
compiled and interpreted execution; they are not a separate FFI library.

The full build also stages the [[file:websocket.org][pinned libwebsockets client dependency]] under
=gen/websocket/= using =lib/websocket/CMakeLists.txt=. It requires OpenSSL
development files and system CA certificates. On Ubuntu/Debian install
=libssl-dev= and =ca-certificates=. CMake =--fresh= keeps the vendor profile
consistent when options change. Static/shared TLS-context smoke tests run as
part of =./make.til test=. The driver then compiles the Til WebSocket transport
to =gen/lib/libnostril_ws.so= and generates =gen/websocket_api.til=. The small
native ABI helper is linked into that library; libwebsockets' shared library is
staged in =gen/lib/= alongside it.

Transport integration tests additionally require Python 3 with =websockets=
(Ubuntu/Debian: =python3-websockets=) and the =openssl= command. The fixture binds
only loopback interfaces, uses temporary test certificates, and is bounded by
a subprocess timeout. No external relay is required by the suite.

The full build also compiles =lib/accounts/nostril_startup.til= as a shared
library and generates =gen/nostril_startup_api.til=, =gen/nostril_runtime.til=
(the matching installed SDK location), and =gen/nostril_init.til= (ready to copy
and edit). The GUI and interpreted init use the same shared state. Runtime
configuration uses TilVm, not a compiler subprocess. The account model test is
built as =bin/nostril-account-tests= and exercised with an empty PATH.

The build driver is executable Til code, =make.til=, rather than a GNU
Makefile. It uses =--cpu=baseline --usize=64 --opt=0= by default.

** Build targets

From the repository root:

#+begin_src sh
./make.til
./make.til library
./make.til test
./make.til clean
#+end_src

Optimization can be selected with =--opt=0=, =--opt=2=, or =--opt=3=:

#+begin_src sh
./make.til --opt=2
./make.til test --opt=2
#+end_src

The default target builds =libnostril= and statically links =bin/nostril-cli=,
=bin/nostril-relay=, and =bin/nostril-gui= against it. The local client and
relay are built with the project-owned modes in =modes.til=. =library= builds
only the archive, shared object, and generated language bindings. =test=
rebuilds the library and clients, then runs =tests.til= through Til's =test=
command. Til interprets the complete suite and then compiles and runs it. The
suite covers the generated binding, ephemeral key generation, NIP-01 signing
and validation, rejection of unsigned and cryptographically invalid events, an
NNG =inproc://= round trip, publisher/subscriber fan-out, a layered two-client
fake-relay lifecycle, and the separate client and relay over =ipc://=.

=clean= removes =bin/=, =gen/=, and =tmp/=. The Git-ignored =.inspirations/=
directory is reserved for reference repositories and is preserved.

** GUI Send regression

The optional X11 test creates a persistent test account in a private HOME,
loads it through TilVm, types heap-owned composer text, clicks Send, checks that
the composer is cleared, submits another note with Enter, and closes the GUI.
It runs local-only and never publishes to a public relay. It requires Xvfb,
=xwininfo=, and X11/XTest libraries in addition to the normal GUI dependencies:

#+begin_src sh
xvfb-run --auto-servernum til run --usize=64 test/gui_send.til
#+end_src

An optional positional argument selects a separately built GUI executable. For
ASan invalid-access checks:

#+begin_src sh
til build --asan --cpu=baseline --usize=64 -o tmp/nostril-gui-asan src/nostril_gui.til
ASAN_OPTIONS=detect_leaks=0 xvfb-run --auto-servernum til run --usize=64 test/gui_send.til tmp/nostril-gui-asan
#+end_src

Leak detection is disabled only in this graphical run: the Mesa/GLX backend on
the test host retains allocations even for an empty window. The headless signer
regression and library/transport ASan checks retain leak detection. The signing
regression signs, edits and clears an owned composer and then validates both
independently owned events; string literals alone would hide this ownership bug.

** Generated files

- =gen/lib/libnostril.a= and =gen/lib/libnostril.so=: generated libraries.
- =gen/til/nostril.*=: generated Til, C, and Python bindings.
- =gen/nostril_api.til=: build-selected static Til interface for local clients.
- =gen/nostril_version.til=: Git-derived version shared by the library and clients.
- =gen/nng/=: NNG CMake tree, static archive, and interpreter twin.
- =gen/nng_link.til=: generated absolute link selection for the custom modes.
- =gen/*.c=: generated C translations.
- =bin/nostril-tests=: compiled =tests.til= runner.
- =bin/nostril-cli=, =bin/nostril-relay=, and =bin/nostril-gui=: application executables.

Generated files are ignored by Git and should not be edited by hand.
