* libnostril

=nostril.til= is the canonical =mode lib= entry point for reusable Nostril
behavior. It exports version metadata plus ephemeral key generation, public-key
derivation, NIP-01 kind-1 signing, event validation, and validated content
extraction from event objects and relay =EVENT= envelopes.

Signing borrows the caller's secret key and content; it does not consume the
composer buffer. The returned signed JSON owns independent bytes, so the caller
can edit or clear the composer immediately after signing.

Verified event-ID accessors support transport-independent deduplication.
Publication helpers produce local OK replies and parse complete matching replies
into accepted/rejected state. Returned strings are owned by the caller; input
strings are borrowed for the duration of the call. Transport sockets, outbox
ownership, retries and session lifetime belong to the host-side live module.

Live subscription helpers parse REQ/CLOSE controls, generate EOSE/CLOSED replies,
and match verified events against filters. Every filter requires =limit:0=;
unsupported fields are rejected. Subscription IDs are scoped by the host to
individual connections; the library itself owns no connection or stored events.

From the repository root:

#+begin_src sh
./make.til library
./make.til test
#+end_src

Til places generated libraries under =gen/lib/= and bindings under =gen/til/=.
See [[file:../../doc/architecture.org][the initial architecture]] for intended component boundaries.
